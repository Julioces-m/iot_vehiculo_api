API RESTful y servidor de WebSockets para el control, monitoreo y ejecución de secuencias automáticas (DEMOs) de vehículos IoT.

## Requisitos Técnicos
- Python 3.10+
- MySQL / AWS RDS
- FastAPI + Uvicorn

## Instalación
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
